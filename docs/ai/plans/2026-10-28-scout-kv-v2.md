# scout_kv v2 (books with a shared latent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the v2 probe's Bflag25 generator into `src/` and `configs/`, then train and judge it on all 12 global layers at training seeds 42 and 1, piloted at L3, L19 and L27.

**Architecture:** A new model module (`src/models/book_latent.py`) holds the per-book drifting latent, the generator and the window critic; v1's flag-conditioned per-token critic is reused as built by `build_critic`. A new trainer (`src/train/train_book_latent.py`) trains on whole books held on the GPU, in batches of 8-token windows, with the two critics side by side. A new sampler (`src/sample/sample_books.py`) writes 8 synthetic books in capture format, which the unchanged `kv_gate measure-real`, `locality.py` and `hub_position.py` score. The v0/v1 trainer, samplers and `measure-run` refuse a book-latent run by name. A pure judge module (`src/kv/book_judge.py`) applies the spec's port check and its two criteria.

**Tech Stack:** Python 3.12, PyTorch, numpy, faiss (gate), pytest; box runs on `tig-gpu-alt` (L40 46 GB, `/workspace/kvenv`, torch `2.14.1+cu126`).

**Spec:** `docs/ai/specs/2026-10-28-scout-kv-v2-book-latent-design.md` (approved 2026-10-28). It builds on `docs/ai/specs/2026-10-18-kv-cache-scout-design.md` and `docs/ai/specs/2026-10-22-scout-kv-v1-position-flag-design.md`. The reference implementation is `docs/results/scout-kv/v2-probe/probe.py` (arm B, `--critic both --window-weight 0.1 --pos flag --tail-share 0.25`). Read the spec and `probe.py` before any task.

## Global Constraints

- Book layout: `T` 32,768 positions; `n_sink` 1 (position 0 is the attention sink); body = positions 1-31,743; tail = positions 31,744-32,767 (`n_tail` 1,024). Training books 0-11; synthetic books are written as 12-19.
- Latent: 64 channels, M = 8 random Fourier features per channel, length scales `ℓ_c = logspace(log10 2, log10 16384, 64)`, `ω_cm ~ N(0,1)/ℓ_c` drawn once from `torch.Generator().manual_seed(seed)` on CPU and stored as a buffer; per-book coefficients `a, b ~ N(0,1)` of shape `(2, 64, 8)`; `u_c(t) = Σ_m (a_cm cos(ω_cm t) + b_cm sin(ω_cm t)) / √M`.
- Generator: input `cat([z (128), u (64), one_hot(flag, 2)])` = 194 columns; hidden 1,024-2,048-4,096; output 5,120; LeakyReLU 0.2; built from `src.models.generator.Generator`. Each token gets its own `z`.
- Flag: `BODY = 0`, `TAIL = 1` from `src/models/conditional.py`; a token is `TAIL` iff its position ≥ `T - n_tail`. Generator, token critic and window critic all take the same 2-column one-hot (my call; the spec allows the probe's 1 bit or v1's one-hot as long as all three match).
- Token critic: v1's, `build_critic({..., "n_flags": 2}, 5120)` = `FlagConditionedCritic(Critic(5122, [2048, 1024, 512]))`; gradient penalty per token.
- Window critic: W = 8 tokens at one stride from {1, 4, 16, 64, 256, 1024}; per-token trunk `Linear(5122,1024)-LeakyReLU-Linear(1024,512)`, then LeakyReLU; token head `Linear(512,1)` averaged over the window; window head `Linear(8·512 + 6, 1024)-LeakyReLU-Linear(1024,512)-LeakyReLU-Linear(512,1)` on the flattened embeddings plus a one-hot of the stride index; score = token-head mean + window head. Gradient penalty over the whole window (one interpolation weight per window, norm over all `W × D` entries).
- Generator loss = `−mean(token score) − 0.1 × mean(window score)`.
- Batches: 64 windows of 8 tokens. Exactly `round(0.25 × 64)` = 16 windows lie wholly in the tail, 48 end in the body (my call: an exact count as v1's `FlagBatchStream`, where the probe drew each window's kind at random with p = 0.25). Stride uniform over those whose window fits. Every fake window is its own fresh book (its own latent coefficients). Real windows: each from one uniformly drawn training book, at the same positions as its fake window.
- Training: 30,000 generator steps, `n_critic` 3 (a fresh fake batch and its real batch per critic iteration, both critics updated on it), Adam lr 1e-4 betas (0, 0.9) for all three networks, `λ_gp` 10 for both critics, EMA 0.999 on the generator (the repo's zero-initialised, bias-corrected EMA from `train_wgan_gp`).
- Data mean: float32 mean over positions 1 … T−1 of books 0-11 (the probe's `RealBooks.mean`); no holdout; no checkpoint selector. Generated `h` = generator output + mean. Synthetic position 0 = the mean.
- v2 is judged on the final EMA weights only.
- Every v0 and v1 config builds, trains, samples, loads and gates exactly as at `origin/main` a0397e4. `load_kv_capture`, `build_training_data`, `synthetic_h` for v0/v1 and `measure-run` are not changed except for the explicit book-latent refusals below. Existing tests stay green untouched.
- `measure_real`'s default record label stays `"source": "real"`.
- Bands in `gates/scout_kv.yaml` and the reference files are not touched (`AGENTS.md`, "What requires a human").
- Baseline at a0397e4: `make check` green, 1231 passed, 1 skipped (MEASURED 2026-10-28, this session).

3. Window positions at the edges: a body window must never include position 0 or a tail position; a tail window must lie wholly in the last 1,024 positions; a stride that does not fit must never be drawn, including for `t_end` at the lowest allowed value. Pinned in Task 1.
4. Books of different lengths, a book too short for `n_sink + n_tail + W`, or a `tail_window_share` that rounds to 0 or to all windows (0.0, 1.0, 0.001 at 64 windows) must raise, not train on an empty class. Pinned in Tasks 1 and 3.
5. Sampling: synthetic position 0 equals the mean; two books from one call differ (their own latents); the same seed gives the same books; an existing output dir is refused; the written capture is readable by `kv_gate.load_books` and `measure_real` with the weights reached through the symlink. Pinned in Task 4.
