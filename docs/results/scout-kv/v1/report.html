Keys and queries are projected through the real W_k and W_q of each KV head, giving 96 corpora, searched with IVF and HNSW under the conditions in gates/scout_kv.yaml. v0 best, re-measured for this report, fails 4 of the 5 bands (full/check_v0_best_seed0.json). Every number on this page is computed from the record files named in each section.

Moves toward real

Rule (spec, "How v1 is judged"): a statistic moves toward real if v1 is inside the target (here the band), or v1's distance outside the band is smaller than v0's by more than the spread. The spread is the pooled spread over the five real draws, except for key-side recall, where it is v0's own difference between the two sampling seeds. A move that closes the gap by less than twice the spread is labelled borderline; it still counts. v0 is the seed-0 measurement. ivf_recall_k128_np24 must stay inside its band. A checkpoint kind is judged as a whole: all-best or all-final, never mixed across layers. v1 meets a criterion if either kind meets it in full.

Caveats

  • No v0 retrain spread. The family has no measurement of how much a retrain of the same v0 configuration moves each statistic. The only noise controls are the five real draws, v0 at two sampling seeds (no retraining), and the borderline label. Same-config retrains in other families moved statistics by more than the reference spread (NYTimes v0, 30k LID 18.0 to 13.8, as quoted in the v1 spec, not re-measured here). The owner chose not to add a v0 retrain.
  • Hardware. All v0 and v1 inputs on this page were measured on the same L40 box (tig-gpu-alt): v0 best was re-measured there, so v0 here may differ from the numbers in the committed v0 report (docs/results/scout-kv/v0/report.html). The real reference draws are earlier records, not re-measured.
  • One sampling seed for v1. v1 is measured at sampling seed 0 only; the second seed exists for v0, and sets the key-side allowance.
  • Checkpoint kinds. Best and final are judged separately and not mixed across layers. Checkpoints measured: v1_best: best_generator.pt, v1_final: checkpoint_step_30000.pt, v0_s0: best_generator.pt, v0_s1: best_generator.pt.
  • Intrinsic diagnostics are single subsamples with no noise band, and the real v0-pooled and per-flag real values come from different subsamples.
  • Inputs. The script stops with an error if any input file is missing or if the check, verdict and record files disagree; a page that exists was built from complete inputs.
